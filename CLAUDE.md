## Карта
- `content/levels/<a1|a2|b1|b2>/lessons/day-NN.json` — уроки (8–12 слов, id `a1-d01-01`), `level.json` — 6 островов по 10 уроков, острова 1–2 бесплатные.
- `content/shop.json` — энергия, награды, товары за ракушки, `stars` (Premium 250⭐/мес, наборы ракушек), `referral`.
- `content/stickers.json` — штампы (не продаются).
- `scripts/validate-content.mjs` — проверки контента (каждое слово примера изучено к уроку, без повторов примеров, без одинаковых переводов в уроке).
- `app/src/engine/` — генерация упражнений (`generators.ts`), проверка ввода/опечаток (`check.ts`), словарь «изучено» (`vocab.ts`: CORE, NAMES, формы).
- `app/src/game/` — логика: `local.ts` (состояние), `session.ts` (награды), `srs.ts` (интервалы), `progress.ts` (острова, «что дальше»), `streak.ts` (костёр), `energy.ts`, `shop.ts`, `stickers.ts`, `purchases.ts` (начисление Stars/друзей), `clock.ts` (защита от подкрутки часов), `time.ts`.
- `app/src/api/` — `content.ts`, `cloud.ts` (копия прогресса в Telegram CloudStorage), `payments.ts` (покупки, приглашения).
- Звуки: `lib/sfx.ts` (Web Audio), жители островов: `components/Residents.tsx`.
- Голос: `lib/speech.ts` играет готовые файлы `app/public/audio/<key>.mp3` (нейросеть Kokoro, голос `af_heart`, ~5000 файлов: все слова и примеры), «Медленнее» = playbackRate 0.72 без смены тона; нет файла → голос телефона. Ключ = cyrb53(норм. текст) — одинаковый в `speech.ts` и `scripts/tts/generate.py` (тест в `tests/logic.test.ts`). **Новый контент → перегенерировать**: `node scripts/tts/texts.mjs > /tmp/t.json && python3 scripts/tts/generate.py /tmp/t.json --model kokoro-v1.0.onnx --voices voices-v1.0.bin` (модель с GitHub releases thewh1teagle/kokoro-onnx; готовые файлы пропускаются).
- `app/src/screens/`, `components/`, `styles/base.css` — интерфейс. Идёт редизайн (см. «Редизайн» ниже).
- `worker/` — сервер оплаты на Cloudflare Workers (подпись initData, счета, вебхук, возвраты, друзья). README там.
- `tests/logic.test.ts` — все тесты (esbuild → node).

## Разнообразие уроков (24.11, решение пользователя: «чтобы не было скучно», экономику не ломать)
- Урок (`engine/generators.ts` → `buildLesson`) каждый раз собирается по-разному: разминка из 2 слов прошлых уроков (`recall`: сначала «созревшие» по `mem.due`), новые слова (карточка → пары/выбор, иногда «верно/нет»), смешанный блок (`varied`: обратный перевод, ввод, пропуск `cloze`, выбор фразы `sentence`, смысл `meaning`, буквы `spell`), 2 на слух, финал: сборка + диктант (`build.audio`). Один вид не идёт дважды подряд.
- Старые слова в уроке — честное повторение: SRS растёт только когда слово «созрело» (`srs.applyAnswer`), так что темп открытия островов не ускоряется.
- Тропа (`game/nodes.ts`): уроки 4 и 8 — «Маяк» (больше на слух), сундук после 5-го урока (+5 ракушек один раз, `s.chests`), кнопки «Испытание» (3 жизни, поражение без награды) и «Шторм» (60 с, `buildStorm`) — обе как `kind: 'trial'`, общий дневной лимит наград испытаний.
- `game/bottle.ts`: «Бутылка с письмом» — раз в день фраза из выученных слов, верно → +3 (Premium ×2), `s.bottleDay`. «Журнал капитана» (`components/LogSheet.tsx`) — текст острова из примеров, без наград.
- Награды сундука/бутылки — в `content/shop.json` → `rewards.chest/bottle`.

## Правила игры (решения пользователя)
- Пройти всё быстро нельзя: острова открываются после закрепления 80% слов (интервалы free 1-3-7, Premium 1-2-4) и паузы между островами.
- Новые слова сначала учатся (карточка, перевод по нажатию), потом задания.
- Костёр: пропуск дня спасает только уголь (без «спасения двумя занятиями»).
- За звёзды продаются только Premium и ракушки. Штампы и острова — никогда.
- Уровень выбирается один раз при входе. Сменить — только через «Удалить прогресс» в профиле (заработанные ракушки сгорают; остаются купленные за звёзды ракушки — `paidCoins`, Premium и учёт покупок/друзей). Когда все уроки уровня пройдены — кнопка «Плыть на уровень X» (только вверх).
- Ракушки: урок 10, без ошибок +5, повторение 6, испытание 5 (Premium ×2).
- Друзья: бонус только за реальных новичков, которые занимались 2 разных дня; не больше 5 друзей.
- Без своего сервера для прогресса: всё на телефоне + CloudStorage. Сервер только для оплаты.
- Telegram-бот, деплой Pages/Worker — самый последний шаг (пользователь скажет).

- Сборка: `VITE_API_URL=https://ostrov-slov-api.iklammm5.workers.dev VITE_APP_LINK=https://t.me/ostrovslov_bot/play npm run build`,
  затем `npx wrangler@4 pages deploy dist --project-name ostrov-slov --branch main` (запускать вне папки проекта или указать абсолютный путь к dist).
- Pages: ~5000 файлов (озвучка) — укладывается в лимит 20 000 файлов. Из облачной сессии pages.dev не открывается (сеть), проверять через API `.../pages/projects/ostrov-slov/deployments`.
- Worker: `cd worker && npx wrangler@4 deploy`. Нужны env `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.
- В боте только мини-приложение: /start — приветствие с кнопкой «Играть», список команд пуст; /paysupport и /terms отвечают (правила Stars), но скрыты.
- Админка: в профиле кнопка «Админка», если id игрока в `ADMIN_IDS` (worker/wrangler.toml). «Себе» — локально (`game/admin.ts`), «другим» — `/api/admin/{users,find,grant}`, подарки приходят через `/api/status` → `grants` (по id, один раз).
- Видео для монтажа: прислать боту файлом/видео → worker кладёт file_id в KV `inbox` → `wrangler kv key get inbox --binding DB --remote` → `getFile` (до 20 МБ).
- Настройка бота: `POST /setup` с заголовком `x-setup-secret: <WEBHOOK_SECRET>` (или те же вызовы Bot API напрямую).
