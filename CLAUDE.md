## Карта
- `content/levels/<a1|a2|b1|b2>/lessons/day-NN.json` — уроки (8–12 слов, id `a1-d01-01`), `level.json` — 6 островов по 10 уроков, острова 1–2 бесплатные.
- `content/shop.json` — энергия, награды, товары за ракушки, `stars` (Premium 250⭐/мес, наборы ракушек), `referral`.
- `content/stickers.json` — штампы (не продаются).
- `scripts/validate-content.mjs` — проверки контента (каждое слово примера изучено к уроку, без повторов примеров, без одинаковых переводов в уроке).
- `app/src/engine/` — генерация упражнений (`generators.ts`), проверка ввода/опечаток (`check.ts`), словарь «изучено» (`vocab.ts`: CORE, NAMES, формы).
- `app/src/game/` — логика: `local.ts` (состояние), `session.ts` (награды), `srs.ts` (интервалы), `progress.ts` (острова, «что дальше»), `streak.ts` (костёр), `energy.ts`, `shop.ts`, `stickers.ts`, `purchases.ts` (начисление Stars/друзей), `clock.ts` (защита от подкрутки часов), `time.ts`.
- `app/src/api/` — `content.ts`, `cloud.ts` (копия прогресса в Telegram CloudStorage), `payments.ts` (покупки, приглашения).
- Звуки: `lib/sfx.ts` (Web Audio), голос: `lib/speech.ts` (только английский), жители островов: `components/Residents.tsx`.
- `app/src/screens/`, `components/`, `styles/base.css` — интерфейс (дизайн готов, не переделывать без просьбы).
- `worker/` — сервер оплаты на Cloudflare Workers (подпись initData, счета, вебхук, возвраты, друзья). README там.
- `tests/logic.test.ts` — все тесты (esbuild → node).

## Правила игры (решения пользователя)
- Пройти всё быстро нельзя: острова открываются после закрепления 80% слов (интервалы free 1-3-7, Premium 1-2-4) и паузы между островами.
- Новые слова сначала учатся (карточка, перевод по нажатию), потом задания.
- Костёр: пропуск дня спасает только уголь (без «спасения двумя занятиями»).
- За звёзды продаются только Premium и ракушки. Штампы и острова — никогда.
- Уровень выбирается один раз при входе. Сменить — только через «Удалить прогресс» в профиле (ракушки, Premium и учёт покупок/друзей сохраняются). Когда все уроки уровня пройдены — кнопка «Плыть на уровень X» (только вверх).
- Ракушки: урок 10, без ошибок +5, повторение 6, испытание 5 (Premium ×2).
- Друзья: бонус только за реальных новичков, которые занимались 2 разных дня; не больше 5 друзей.
- Без своего сервера для прогресса: всё на телефоне + CloudStorage. Сервер только для оплаты.
- Telegram-бот, деплой Pages/Worker — самый последний шаг (пользователь скажет).
