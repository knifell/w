# Промпт для нового чата: стиль и дизайн

Скопируй текст ниже в новый чат Claude Code с репозиторием `knifell/w`.

---

Ты мой дизайнер и фронтенд-разработчик. Репозиторий `knifell/w`, ветка `claude/great-einstein-uwteae`. Работай только в этой ветке.

**Проект:** «Остров слов», Telegram Mini App для изучения английского в виде игры. Механика, логика и контент **полностью готовы**. Задача — только стиль и дизайн. Сервер и Telegram не трогаем, они будут в самом конце.

**Стек:** Vite + Preact + TypeScript, без UI-библиотек. Стили в `app/src/styles/base.css`, цвета через CSS-переменные (`--tg-bg`, `--tg-text`, `--tg-accent` и др.). Их подменяет тема Telegram, поэтому дизайн должен работать в светлой и тёмной теме.

**Что можно менять:**
- `app/src/styles/*` — стили, цвета, шрифты, анимации;
- разметку и классы в `app/src/screens/*` и `app/src/components/*`, если это нужно для дизайна;
- добавлять свою графику: SVG, иконки, иллюстрации маскота (краб Шкипер), острова на карте.

**Что менять нельзя** (это готовая логика):
- `app/src/game/*` — экономика, энергия, интервальные повторения, открытие островов, штампы;
- `app/src/engine/*` — генерация и проверка упражнений;
- `content/*` — уроки, лавка, штампы;
- `scripts/*`, `tests/*`;
- props, обработчики и порядок шагов в экранах. Поведение должно остаться тем же.

**Экраны:** приветствие → выбор уровня → мини-тест → карта островов (верхняя панель, нижнее меню) → урок (новое слово с подсказкой, выбор перевода, пары, ввод, сборка предложения, окно ответа) → итог урока. Ещё паспорт штампов, лавка, профиль, Premium, «О проекте», окно энергии, глава сюжета.

**Правила:**
- Качество уровня Duolingo, но свой стиль. Не копировать чужие названия, персонажей, цвета-бренды и графику.
- Сначала мобильная вёрстка (360–430 px). Крупные кнопки, удобные пальцу.
- Бюджет $0: только бесплатные шрифты и свои SVG, без платных ассетов.
- После изменений запусти `npm run typecheck`, `npm test`, `npm run build`. Всё должно пройти.
- Коммить по этапам и пушь в ту же ветку.

**Превью:** `npm run dev` или сборка с `npx vite build app --base ./`. Текущее превью: https://claude.ai/artifact/33fq2f8kAwKuvYbkWh2s19

Начни с короткого плана: стиль, палитра, шрифты, что меняешь на каждом экране. Покажи его и жди моего ОК, только потом пиши код.
