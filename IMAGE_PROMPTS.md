# Картинки для «Острова слов» (Google Flow → Nano Banana, 2K)

Как делать:
1. Сначала сгенерируй **№1** (Шкипер). Если понравился, в следующих промптах добавляй его как референс («ingredient» / reference image): так краб будет одинаковым на всех картинках.
2. Пропорции ставь в настройках Flow, как указано у каждой картинки.

4. Если на картинке появились буквы, лишние лапы или кривые глаза, перегенерируй.

Общий стиль уже есть в каждом промпте, менять его не нужно.
