# PLAN — «Остров слов» (рабочее название)

Telegram Mini App для изучения английского в формате игры. Бюджет $0.

## 0. Своя механика и названия (не копия Duolingo)
- Мир = **архипелаг**. Уровень (A1/A2/B1/B2) = свой архипелаг. Карта = остров, 10 уроков-«стоянок» на острове.
- Маскот: краб-картограф **Шкипер** (своя SVG-графика, эмодзи до готовой графики).
- XP = «опыт», монеты = **ракушки 🐚**, серия = **костёр 🔥** (дни подряд), энергия = **фонарь ⚡** (масло).
- Наклейки = **штампы в паспорте путешественника** (альбомы-коллекции по островам и событиям).
- Зелья: **Попутный ветер** (×2 XP 15 мин), **Тлеющий уголь** (защита серии на 1 пропуск).
- Отличие от Duolingo: энергия тратится на **старт урока**, ошибки не отнимают жизни; ошибка → слово возвращается в конец урока.

## 1. Стек ($0)
| Часть | Решение |
|---|---|
| Фронтенд | Vite + Preact + TypeScript, Cloudflare Pages (`*.pages.dev`, без домена) |
| БД / API | Supabase Free: Postgres + RLS + RPC (SQL-функции) |
| Вход | Edge Function `tg-auth`: проверка `initData` (HMAC от токена бота) → upsert пользователя → свой JWT (подпись JWT-секретом проекта) |
| Бот | Edge Function `bot` как webhook (без отдельного сервера): /start, кнопка Mini App, оплата Stars |
| Оплата | Telegram Stars (`XTR`), подписка через `createInvoiceLink` с `subscription_period=2592000` (30 дн.) |
| Контент | Статичные JSON в `content/`, копируются в сборку |

Компромисс бесплатного стека: JSON-контент публичен (статикой). Защищено главное — прогресс, награды и доступ проверяются на сервере (RPC).

## 3. Схема JSON-урока
`content/levels/b1/lessons/day-07.json`
```json
{
  "id": "b1-d07",
  "level": "B1",
  "day": 7,
  "island": 1,
  "title": "At the airport",
  "topic": "travel",
  "words": [
    {
      "id": "b1-d07-01",
      "en": "boarding pass",
      "ru": ["посадочный талон"],
      "pos": "noun",
      "examples": [
        { "en": "Please show your boarding pass at the gate.",
          "ru": "Пожалуйста, покажите посадочный талон у выхода." }
      ]
    }
  ]
}
```
Правила: 8–12 слов (цель 10), 1–2 примера, пример содержит слово (или его форму — поле `form`, опционально), `ru` — массив допустимых переводов, `id` уникальны глобально.

`level.json`: `{ "level":"B1", "islands":[{ "n":1, "name":"…", "days":[1,10], "story":"короткая глава", "free":true }] }`
Поле `"free": true` только у первого острова.

## 4. Генерация упражнений (код, не JSON)
Вход: слова урока + пул слов того же уровня (для дистракторов). Seeded RNG → повторяемость.
1. **Выбор перевода** EN→RU и RU→EN, 4 варианта, дистракторы той же части речи.
2. **Пары**: 5 пар EN↔RU.
3. **Ввод слова**: RU → набрать EN; нормализация регистра/пробелов, 1 опечатка допустима для слов ≥6 букв.
4. **Сборка предложения**: из примера, токены перемешаны + 1–2 лишних слова.
Урок ≈ 12–15 заданий, у каждого слова ≥1 появление; ошибки возвращаются в очередь.
Повторение: в урок дня добавляются 2–3 слова из прошлых уроков (слабые — по статистике ошибок).

## 5. Проверка контента (`scripts/validate-content.mjs`)
- дубли: `id` (глобально), `en` внутри уровня и **между уровнями** (B1 не содержит слов A1/A2);
- пустые поля, неверные типы, нет примеров / >2 примеров;
- `level` в файле ≠ папке, `id` не с префиксом уровня, `day` ≠ имени файла;
- пропуски дней, <30 уроков на уровень (warning, пока контент растёт);
- пример не содержит слово (warning).
Выход: код 1 при ошибках → CI красный, сборка не идёт.

## 6. Экраны
1. **Splash / вход** — авторизация через initData.
2. **Онбординг** — 3 карточки: что за игра + пометка «контент растёт».
3. **Тест уровня** — ~16 вопросов (по 4 на уровень, адаптивно: 2 ошибки на уровне → стоп) → результат A1/A2/B1/B2, можно пересдать.
4. **Карта** — острова уровня, стоянки-уроки, замки, баннер «Контент и сюжет дополняются».
5. **Сюжетная глава** — короткий текст при входе на остров.
6. **Урок** — задания, прогресс-бар, фидбек, haptics.
7. **Итог урока** — XP, ракушки, костёр, новые штампы.
8. **Паспорт (коллекции)** — альбомы штампов, редкость, прогресс.
9. **Лавка** — бусты/зелья за ракушки (штампы не продаются).
10. **Профиль** — уровень, статистика, серия, смена уровня (Premium).
11. **Premium** — преимущества, оплата Stars.
12. **О проекте** — честно: версия контента, что готово, что в планах.

## 7. Схема БД (Supabase)
Вся запись — только через RPC/Edge Functions (`security definer`). RLS: пользователь читает только свои строки.
```sql
users          (id uuid pk, tg_id bigint unique, name, lang, level text check in(A1,A2,B1,B2),
                created_at)
wallet         (user_id pk, xp int, coins int, energy int, energy_at timestamptz)
streak         (user_id pk, current int, best int, last_day date, shields int)
progress       (user_id, lesson_id text, best_score int, stars smallint, done_at, pk(user_id,lesson_id))
word_stats     (user_id, word_id text, seen int, wrong int, last_at, pk(user_id,word_id))
inventory      (user_id, item_id text, qty int, pk(user_id,item_id))
active_boosts  (user_id, item_id text, until timestamptz)
user_stickers  (user_id, sticker_id text, got_at, pk(user_id,sticker_id))
subscriptions  (user_id pk, active_until timestamptz, tg_charge_id text, is_recurring bool)
payments       (id pk, user_id, tg_charge_id unique, stars int, payload text, created_at)
```
RPC: `start_lesson(lesson_id)` (проверка доступа + энергии), `complete_lesson(lesson_id, score, mistakes jsonb)` (сервер считает XP/ракушки/серию/бусты/штампы, лимит наград в сутки против накрутки), `buy_item(item_id)`, `use_item(item_id)`, `set_level(level)`.

## 8. Экономика (стартовые числа, правятся в `shop.json`)
| | Бесплатно | Premium |
|---|---|---|
| Энергия | 5, +1 / 30 мин, урок = 1 | безлимит |
| Доступ | 1-й остров своего уровня | все острова, все уровни |
| Ракушки за урок | 5 (+5 без ошибок) | ×2 |
| Штампы | обычные/редкие за достижения | + эксклюзивные Premium-штампы |
- Урок: 10 XP, +5 без ошибок; ×2 при «Попутном ветре».
- Лавка: Попутный ветер 100 🐚, Тлеющий уголь 200 🐚 (макс. 2), +3 энергии 60 🐚.
- Штампы за: серию 3/7/30/100, 1-й остров, 100 слов, 10 уроков без ошибок, ночной урок и т.п. Купить нельзя.
- Premium: ~250 ⭐/мес (точно — на твоё решение).

## 9. Этапы
1. Каркас app + контент-схема + валидатор + 3 урока A2/B1 для проверки.
2. Движок упражнений + экран урока (офлайн, localStorage).
3. Тест уровня, карта, итог урока.
4. Supabase: миграция, `tg-auth`, RPC, синхронизация.
5. Экономика: лавка, бусты, паспорт штампов.
6. Бот + Stars-подписка.
7. Деплой Cloudflare Pages + инструкция настройки (BotFather, Supabase, переменные).
8. Наполнение: A2 и B1 по 30 дней (по 300 слов), затем A1, B2.
